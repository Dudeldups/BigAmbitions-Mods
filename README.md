# Big Ambitions Mods by Noctirix

Welcome to the source repository for my **Big Ambitions** mods.

Here you can browse the source files, assets, documentation, and attribution information for my publicly released mods.

## Steam Workshop

The easiest way to install and use my mods is through the Steam Workshop:

**[View my Big Ambitions Workshop items](https://steamcommunity.com/id/Noctirix/myworkshopfiles/?appid=1331550)**

The Workshop versions contain the ready-to-use packages and are the recommended way to install the mods.

## About This Repository

Each top-level folder represents one of my published Big Ambitions mods.

Depending on the mod, the source may include:

- C# source code
- Unity assets and prefabs
- Configuration files
- Localization files
- Models and materials
- Audio files
- Documentation
- Attribution and third-party license information
- Workshop descriptions and changelogs

Build output, temporary development files and packaged Workshop AssetBundles are not included.

## Building From Source

These mods are made for the official **Big Ambitions Modding SDK** and Unity `2022.3.62f2`.

Building a mod yourself may require the official SDK, Big Ambitions game assemblies and, depending on the mod, additional dependencies.

For normal gameplay, using the Steam Workshop version is recommended.
