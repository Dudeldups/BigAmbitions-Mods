[h1]Vehicle Repainter[/h1]

無需購買新車，即可讓您的車輛煥然一新。Vehicle Repainter 將自然融入遊戲的[b]重新烤漆[/b]選項直接加入加油站現有的維修與洗車服務中。

[h2]使用方式[/h2]
[list]
[*] 將車輛駛入加油站的一般維修與洗車服務區。
[*] 選擇[b]重新烤漆（800 美元）[/b]。
[*] 從依色調排列的 96 種擴充顏色中選擇，並直接在車輛上即時預覽每種顏色。
[*] 新增漆面：原廠、霧面、緞面、亮面及高亮面。漆面可獨立於顏色選擇。
[*] 漆面會依車輛分別儲存，讀取存檔後恢復。
[*] 重新烤漆的價格依漆面而定，介於 800 至 1,800 美元。
[/list]

[h2]相容性[/h2]
Vehicle Repainter 支援原版車輛，以及使用 Big Ambitions 標準車輛顏色系統的相容模組車輛。
