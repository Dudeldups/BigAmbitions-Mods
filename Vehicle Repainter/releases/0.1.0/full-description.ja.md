[h1]Vehicle Repainter[/h1]

新しい車を買わずに、愛車の外観を一新できます。Vehicle Repainterは、ガソリンスタンドにある既存の修理・洗車サービスへ、自然な形で[b]再塗装[/b]オプションを追加します。

[h2]使い方[/h2]
[list]
[*] 車両をガソリンスタンドの通常の修理・洗車スペースに入れます。
[*] [b]再塗装（800ドル）[/b]を選択します。
[*] 色合い順に並んだ96色の拡張パレットから選び、それぞれを車両上で直接プレビューできます。
[*] 新しい塗装仕上げ：純正、マット、サテン、光沢、高光沢。色とは別に仕上げを選べます。
[*] 仕上げは車両ごとに保存され、セーブデータの読み込み時に復元されます。
[*] 再塗装の価格は仕上げによって変わり、800～1,800ドルです。
[/list]

[h2]互換性[/h2]
Vehicle Repainterは、バニラ車両と、Big Ambitionsの標準車両カラーシステムを使用する互換性のあるMod車両に対応しています。
