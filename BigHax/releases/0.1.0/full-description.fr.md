[h1]Big Hax[/h1]

Soyons honnêtes : parfois, la vie de magnat des affaires demande vraiment trop de travail honnête. C’est là qu’intervient [b]Big Hax[/b] – un mod de triche léger conçu pour prendre les raccourcis que vous n’aviez de toute façon aucune envie de contourner.

N’hésitez pas à proposer les autres Hax dont vous auriez besoin.
