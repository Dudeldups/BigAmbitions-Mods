[h1]Big Hax[/h1]

솔직히 말해 봅시다. 사업 거물의 삶에는 가끔 너무 많은 ‘정직한 노동’이 필요하죠. 그래서 [b]Big Hax[/b]가 등장했습니다. 어차피 돌아가기 싫었던 길을 시원하게 지름길로 만들어 주는 가벼운 치트 모드입니다.

추가로 필요한 Hax가 있다면 언제든 제안해 주세요.

[hr][/hr]

[h2]현재 기능:[/h2]

[b]돈 핵[/b]
[list]
[*] 카지노 베팅 한도 올리기
[*] 투자 한도 비활성화
[*] Vantander Bank 최대 대출액을 100,000,000 $로 올리기
[/list]

[b]직원 핵[/b]
[list]
[*] 채용 후보자의 기술을 최대 100%까지 허용
[*] 모든 직원 요구 사항 제거
[*] 모든 직원 만족도를 100%로 설정
[*] 직원 교육 스킬 증가량 (10~100)
[*] 헤드헌터 채용 포인트를 1000으로 증가
[*] HR 관리자 최대 담당 직원 수 (50~10,000)
[/list]

[b]플레이어 핵[/b]
[list]
[*] 허기 및 에너지 감소 비활성화
[*] 행복 감소 비활성화
[/list]

[b]잠금 해제 핵[/b]
[list]
[*] 모든 연락처 잠금 해제
[*] 모든 과정 잠금 해제
[/list]

[b]사업 핵[/b]
[list]
[*] 즉시 수입
[*] 즉시 가구 배달
[*] 수입 한도 비활성화
[*] 설치 업체 수수료 (0~100%)
[*] 플레이어 사업 고객 배율 (1x–10x)
[/list]

[b]차량 핵[/b]
[list]
[*] 불법 주차 벌금 비활성화
[*] 차량 피해 없음
[*] 무한 차량 연료
[*] 차량이 더러워지지 않음
[*] Delivery Truck 배송 지점 (8–160)
[/list]

[b]용량 핵[/b]
[list]
[*] Standard Fridge 용량 (50~1000)
[*] Pallet Shelf 용량 (60~1000)
[*] Storage Shelf 용량 (16~1000)
[*] 활성 차량 용량 재정의 (1000)
[/list]

[b]시간 핵[/b]
[list]
[*] 벤치에서 쉴 수 있는 시간을 24시간으로 연장 (기본 활성화)
[*] 침대에서 잘 수 있는 최대 시간을 7일로 연장
[*] 침대에서 오래 잘 때 시간이 더 빠르게 흐릅니다.
[/list]

사용 가능한 모든 치트는 선택 사항이므로, 필요한 것만 골라서 활성화하세요.
