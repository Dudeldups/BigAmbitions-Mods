[h1]Big Hax[/h1]

Ας είμαστε ειλικρινείς: μερικές φορές η ζωή ενός μεγιστάνα επιχειρήσεων απαιτεί υπερβολικά πολλή... τίμια δουλειά. Εδώ έρχεται το [b]Big Hax[/b] – ένα ελαφρύ cheat mod που υπάρχει για να κόβει τις γωνίες που έτσι κι αλλιώς δεν ήθελες να περπατήσεις.

Και φυσικά, οι προτάσεις για άλλα Hax που χρειάζεσαι είναι ευπρόσδεκτες.
