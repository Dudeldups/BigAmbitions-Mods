[h1]Big Hax[/h1]

正直に言いましょう。ビジネス界の大物として生きるのは、ときどき「真面目な仕事」が多すぎます。そこで登場するのが [b]Big Hax[/b]。どうせ回り道なんてしたくなかった人のために、面倒な部分をショートカットする軽量チートModです。

ほかにも欲しい Hax があれば、ぜひ提案してください。

[hr][/hr]

[h2]現在の機能:[/h2]

[b]資金ハック[/b]
[list]
[*] カジノの賭け金上限を引き上げる
[*] 投資上限を無効化
[*] Vantander Bankの最大融資額を100,000,000 $に引き上げる
[/list]

[b]従業員ハック[/b]
[list]
[*] 採用候補者のスキル上限を100%にする
[*] 従業員の要求をすべて削除
[*] すべての従業員の満足度を100%に設定
[*] 従業員研修のスキル上昇量 (10～100)
[*] ヘッドハンターの採用ポイントを1000に増加
[*] 人事マネージャーの最大担当人数 (50～10,000)
[/list]

[b]プレイヤーハック[/b]
[list]
[*] 空腹とエネルギーの減少を無効化
[*] 幸福度の減少を無効化
[/list]

[b]アンロックハック[/b]
[list]
[*] すべての連絡先をアンロック
[*] すべてのコースをアンロック
[/list]

[b]事業ハック[/b]
[list]
[*] 即時輸入
[*] 即時家具配達
[*] 輸入制限を無効化
[*] 設置業者の料金 (0～100%)
[*] プレイヤー企業の顧客倍率 (1x–10x)
[/list]

[b]車両ハック[/b]
[list]
[*] 違法駐車の罰金を無効化
[*] 車両ダメージなし
[*] 車両燃料無限
[*] 車両が汚れない
[*] Delivery Truckの配送先数 (8–160)
[/list]

[b]容量ハック[/b]
[list]
[*] Standard Fridgeの容量 (50～1000)
[*] Pallet Shelfの容量 (60～1000)
[*] Storage Shelfの容量 (16～1000)
[*] アクティブ車両の容量上書き (1000)
[/list]

[b]時間ハック[/b]
[list]
[*] ベンチで休める時間を 24 時間に延長（デフォルトで有効）
[*] ベッドで眠れる最大時間を7日間に延長
[*] 長時間のベッド睡眠で、時間がより速く進むようになりました。
[/list]

利用可能なチートはすべて任意なので、必要なものだけ有効にしてください。

ゲーム標準風の UI が欲しい場合は、[url=https://steamcommunity.com/sharedfiles/filedetails/?id=3790426259]LIB BA Unified UI[/url] を任意で使用できます
