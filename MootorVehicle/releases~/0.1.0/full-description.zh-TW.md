[h1]Moo-tor Vehicle[/h1]

既然可以擁有[b]牛力[/b]，為什麼還要滿足於馬力？

[h2]功能[/h2]
[list]
[*] 花費 $1,800 在 City Cars 購買乳牛並擁有牠。
[*] 透過標準載具系統騎乘、轉向、煞車、下牛、停車及儲存。
[*] 可以免費停在人行道上，也不會收到罰單。
[*] 騎乘時角色保持可見，採用騎牛姿勢，手中攜帶的包裹也會顯示。
[*] 行走時腿部會有動畫，耳朵偶爾會擺動。
[*] 以牛叫聲代替喇叭聲，碰撞時會發出牛叫，乳牛停在附近時還會偶爾發出具有空間感的叫聲。
[*] 符合乳牛特性的操控，普通最高速度約為 22 公里/小時。
[*] 強烈碰撞會使乳牛受傷，並可能將騎手甩到地上。
[/list]

[h2]餵食與能量模式[/h2]

加油站無法為乳牛補充能量。手持一罐能量飲料或一箱能量飲料騎上乳牛，即可餵食。系統會消耗一罐飲料，將乳牛的能量補充至 100%，並啟用能量模式，使速度加倍直到能量耗盡。

[h2]包裹[/h2]

乳牛沒有後車廂。

因為牠是一頭牛。

騎乘時手持的包裹會繼續顯示在騎手手中；下牛後，包裹會恢復為一般手持物品操作。

[h2]治療[/h2]

乳牛無法使用一般加油站和維修站。必須安裝 Mobile Veterinarian；玩家騎在乳牛上時，它可以治療受到的傷害。
