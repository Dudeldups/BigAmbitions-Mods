# Model source

`vw_t1_style_bus_free.glb` is the supplied VW T1 style bus model by Libau Media (Robin Mikart), Sketchfab, CC BY 4.0. Attribution and license details are in the mod-root `ATTRIBUTION.md` and `THIRD_PARTY_NOTICES.md`.

The setup script normalizes the model to the documented T1 length, places its four source wheel assemblies on the researched track and wheelbase, bakes the red/cream outer shell for damage deformation, and creates independent state-controlled auxiliary lamp surfaces where the GLB has no separate geometry.
