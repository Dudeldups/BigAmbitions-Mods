[b]Goodbye IRS[/b]

を使えば、現在のセーブデータでIRSを完全に無効化できます。

[b]やり方：[/b]

[list]
[*] ガソリンスタンドでジェリカン（携行缶）を購入する
[*] 営業時間内にIRSの建物を訪れる
[*] やるべきことをやる
[/list]

[hr]

[b]免責事項[/b]

このMODは、あくまで馬鹿げたゲームプレイの選択肢として作られたものです。

現実の税金問題をガソリン携行缶で解決しようとしないでください。
