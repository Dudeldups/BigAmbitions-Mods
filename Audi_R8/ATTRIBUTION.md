# Audi R8 model attribution

The supplied model was created by [Ddiaz Design](https://sketchfab.com/ddiaz-design).
[Original model source](https://sketchfab.com/3d-models/2021-audi-r8-green-hell-edition-8ab3e0f5f18b46508fd9caefbf0f9b33).
The embedded model metadata specifies
[Creative Commons Attribution–NonCommercial–ShareAlike 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).

Changes for this mod include fitting the model to the vehicle axes and dimensions,
separating wheels, calipers, paint and lamp faces, creating deformation meshes
and removing the opaque lamp cover faces at runtime. The adapted model retains
the source model's license. The displayed vehicle name is **Audi R8**.

The engine WAVs are original synthetic audio generated by this mod's script.
They contain no source recording or sample copied from another vehicle mod.
