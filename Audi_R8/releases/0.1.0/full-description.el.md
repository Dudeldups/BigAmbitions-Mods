Γρήγορο, εκλεπτυσμένο και αναμφισβήτητα Audi, το R8 αποδεικνύει ότι ένα supercar δεν χρειάζεται να είναι μη πρακτικό. Προσφέρει επιδόσεις εξωτικού αυτοκινήτου χωρίς να δείχνει εκτός τόπου στην καθημερινή μετακίνηση.
