[h1]McLaren Senna[/h1]

Ekstremalna aerodynamika, brutalne przyspieszenie i absolutny brak zainteresowania dyskrecją. McLaren Senna jest tak bliski samochodowi wyścigowemu z tablicami rejestracyjnymi, jak tylko się da.
