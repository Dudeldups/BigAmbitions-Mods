[h1]McLaren Senna[/h1]

Äärimmäistä aerodynamiikkaa, rajua kiihtyvyyttä eikä pienintäkään kiinnostusta huomaamattomuuteen. McLaren Senna on niin lähellä kilpa-autoa rekisterikilvillä kuin voi päästä.
