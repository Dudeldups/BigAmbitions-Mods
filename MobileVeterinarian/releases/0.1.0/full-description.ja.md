[h1]Mobile Veterinarian[/h1]

ゲーム内の電話から移動獣医を呼び、現在乗っている騎乗動物を治療できます。

[b]必須アイテム：[/b] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3795463421]Custom NPC API[/url]

[h2]利用方法[/h2]

[list]
[*] 対応している動物に乗り、停止させます
[*] 通常の電話連絡先から Mobile Veterinarian に電話します
[*] 動物の実際の損傷率から算出された料金を確認します
[*] 電話を閉じ、獣医が治療している間は乗ったままでいてください
[*] 車両の実際の損傷状態が完全に修復された後にのみ料金が発生します
[/list]

獣医は安全に立てる場所を見つけるため、動物の両側を確認します。訪問がキャンセルまたは失敗した場合、料金は一切かかりません。

[h2]対応動物[/h2]

[url=https://steamcommunity.com/sharedfiles/filedetails/?id=3798865703]Moo-tor Vehicle[/url] の騎乗可能な牛に標準対応しています。Moo-tor Vehicle は任意であり、この Mod には同梱されていません。

ほかの騎乗動物 Mod は、公開レジストリを通じて正確な VehicleType、ローカライズされた動物名、希望する治療位置を登録できます。サービスのすべてのメッセージには動物 Mod が指定した名前が使われます。使用できる名前が登録されていない場合は「あなたの動物」が使われます。
