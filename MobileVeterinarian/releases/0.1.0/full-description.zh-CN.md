[h1]Mobile Veterinarian[/h1]

使用游戏内电话呼叫上门兽医，为你当前骑乘的动物治疗。

[b]必需项目：[/b] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3795463421]Custom NPC API[/url]

[h2]使用方法[/h2]

[list]
[*] 骑上一只受支持的动物并将其停稳
[*] 从常规电话联系人中呼叫 Mobile Veterinarian
[*] 查看根据动物实际损伤百分比计算出的价格
[*] 关闭电话，并在兽医治疗期间保持骑乘状态
[*] 仅在真实的载具损伤状态完全修复后付款
[/list]

兽医会检查动物两侧，以寻找安全的站立位置。访问被取消或失败时，绝不会向玩家收费。

[h2]支持的动物[/h2]

默认支持 [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3798865703]Moo-tor Vehicle[/url] 中可骑乘的奶牛。Moo-tor Vehicle 为可选项目，未包含在本模组中。

其他骑乘动物模组可通过公共注册表登记准确的 VehicleType、本地化动物名称和首选治疗位置。所有服务消息都会使用动物模组提供的名称；如果登记时未提供可用名称，则会使用“你的动物”。

[h2]面向模组作者[/h2]

[url=https://github.com/Dudeldups/big-ambitions-mods/tree/main/Assets/Mods/MobileVeterinarian]README 和 Mobile Veterinarian 集成指南[/url]包含以下内容：

[list]
[*] 程序集和外部构建依赖项设置
[*] 注册和卸载清理
[*] 本地化动物名称
[*] 治疗位置坐标和对侧自动备选位置
[*] 针对性的集成测试检查清单
[/list]

[h2]兼容性[/h2]

适用于 Big Ambitions build 3674。
