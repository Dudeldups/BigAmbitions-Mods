[h1]Mobile Veterinarian[/h1]

Вызовите мобильного ветеринара по внутриигровому телефону, чтобы вылечить ездовое животное, на котором вы сейчас находитесь.

[b]Требуемый предмет:[/b] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3795463421]Custom NPC API[/url]

[h2]Как это работает[/h2]

[list]
[*] Оседлайте поддерживаемое животное и остановитесь
[*] Позвоните в Mobile Veterinarian через обычный список контактов телефона
[*] Проверьте цену, рассчитанную на основе фактического процента повреждений животного
[*] Закройте телефон и оставайтесь верхом, пока ветеринар проводит лечение
[*] Оплата производится только после полного устранения фактических повреждений транспорта
[/list]

Ветеринар проверяет обе стороны животного, чтобы найти безопасное место. За отменённый или неудавшийся визит плата с игрока не взимается.

[h2]Поддерживаемые животные[/h2]

Ездовая корова из [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3798865703]Moo-tor Vehicle[/url] поддерживается по умолчанию. Moo-tor Vehicle является необязательным и не входит в состав этого мода.

Другие моды с ездовыми животными могут зарегистрировать через открытый реестр точный VehicleType, локализованное название животного и предпочтительную позицию для лечения. Все сообщения службы используют название, предоставленное модом животного; если подходящее название не указано, используется «ваше животное».
