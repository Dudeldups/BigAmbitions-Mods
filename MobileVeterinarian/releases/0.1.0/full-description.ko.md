[h1]Mobile Veterinarian[/h1]

게임 내 전화로 이동 수의사를 불러 현재 타고 있는 동물을 치료하세요.

[b]필수 항목:[/b] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3795463421]Custom NPC API[/url]

[h2]이용 방법[/h2]

[list]
[*] 지원되는 동물에 올라탄 뒤 정지하세요
[*] 일반 전화 연락처에서 Mobile Veterinarian에 전화하세요
[*] 동물의 실제 손상률에 따라 계산된 비용을 확인하세요
[*] 전화를 닫고 수의사가 치료하는 동안 계속 동물에 타고 있으세요
[*] 실제 차량 손상 상태가 완전히 수리된 뒤에만 비용을 지불합니다
[/list]

수의사는 안전하게 설 자리를 찾기 위해 동물의 양쪽을 확인합니다. 방문이 취소되거나 실패하면 플레이어에게 비용이 청구되지 않습니다.

[h2]지원 동물[/h2]

[url=https://steamcommunity.com/sharedfiles/filedetails/?id=3798865703]Moo-tor Vehicle[/url]의 탈 수 있는 소를 기본으로 지원합니다. Moo-tor Vehicle은 선택 사항이며 이 모드에 포함되어 있지 않습니다.

다른 탑승 동물 모드는 공개 레지스트리를 통해 정확한 VehicleType, 현지화된 동물 이름, 선호 치료 위치를 등록할 수 있습니다. 모든 서비스 메시지는 동물 모드가 제공한 이름을 사용하며, 사용할 수 있는 이름이 없으면 “내 동물”을 대신 사용합니다.
