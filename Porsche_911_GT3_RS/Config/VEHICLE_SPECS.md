# 2023 Porsche 911 GT3 RS (992) implementation targets

Primary source: Porsche AG, Technical Data MY P 08/2022:
https://newsroom.porsche.com/dam/jcr:1d390f77-93c3-49c0-89c7-634f5f02b26a/S22_3515_en.pdf

- 4.0 L naturally aspirated six-cylinder boxer; 386 kW (525 PS) at 8,500 rpm
- 465 Nm at 6,300 rpm; maximum engine speed 9,000 rpm
- Rear-wheel drive; seven-speed PDK; final drive 4.27
- Ratios: reverse 3.42; forward 3.75, 2.38, 1.72, 1.34, 1.11, 0.96, 0.84
- DIN mass 1,450 kg; 64 L fuel tank
- Length 4.572 m; width 1.900 m; height 1.322 m; wheelbase 2.457 m
- Track width 1.630 m front and 1.582 m rear
- Tires 275/35 ZR20 front and 335/30 ZR21 rear
- Brakes 408 x 36 mm front and 380 x 30 mm rear
- Top speed 296 km/h; 0-100 km/h 3.2 s; 0-200 km/h 10.6 s
- Drag coefficient 0.39; reference MSRP USD 223,800 before destination

The game physics values use these figures as targets and are tuned within NWH
Vehicle Physics rather than presented as a full vehicle-dynamics simulation.
