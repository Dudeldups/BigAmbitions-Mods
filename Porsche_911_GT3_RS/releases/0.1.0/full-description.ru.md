[h1]Porsche 911 GT3 RS[/h1]

Меньше роскошного гран-туризмо, больше допущенного на дороги гоночного автомобиля. Porsche 911 GT3 RS создан для игроков, которым нужен быстрый, острый и бескомпромиссно ориентированный на производительность автомобиль.

[hr][/hr]

[h2]Характеристики автомобиля[/h2]

[b]Тип:[/b] Допущенный на дороги гоночный автомобиль
[b]Максимальная скорость:[/b] 296 км/ч
[b]0–100 км/ч:[/b] 3,2 секунды
[b]Грузоподъемность:[/b] 2 слота
[b]Дилер:[/b] Manhattan Luxury Cars и The Hamptons Axis
[b]Цена:[/b] $250,000

Ускорение и торможение настроены так, чтобы максимально соответствовать реальному автомобилю.

Автомобиль можно зарегистрировать в службах личного водителя.
