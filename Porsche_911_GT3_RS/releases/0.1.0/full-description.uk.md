[h1]Porsche 911 GT3 RS[/h1]

Менше розкішного гран-туризмо, більше дорожнього гоночного автомобіля. Porsche 911 GT3 RS створено для гравців, які хочуть щось швидке, гостре та безкомпромісно орієнтоване на продуктивність.

[b]Тип:[/b] Дорожній гоночний автомобіль
[b]Максимальна швидкість:[/b] 296 км/год
[b]0–100 км/год:[/b] 3,2 секунди
[b]Вантажна місткість:[/b] 2 слоти
