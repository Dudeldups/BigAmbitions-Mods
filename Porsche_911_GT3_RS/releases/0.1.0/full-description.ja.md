[h1]Porsche 911 GT3 RS[/h1]

高級クルーザーというより、公道走行可能なレーシングカー。Porsche 911 GT3 RS は、速さ、鋭さ、そして徹底的にパフォーマンスを重視した車を求めるプレイヤーのための一台です。
