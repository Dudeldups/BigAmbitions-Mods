[h1]Porsche 911 GT3 RS[/h1]

Kevesebb luxus túraautó, több közútra engedélyezett versenyautó. A Porsche 911 GT3 RS azoknak a játékosoknak készült, akik valami gyorsat, éleset és könyörtelenül teljesítményközpontút szeretnének.
