[h1]Porsche 911 GT3 RS[/h1]

少一點豪華巡航車的風格，多一點可合法上路的賽車本色。Porsche 911 GT3 RS 專為追求速度、銳利操控與毫不妥協性能的玩家打造。

[hr][/hr]

[h2]車輛規格[/h2]

[b]類型：[/b] 可合法上路的賽車
[b]最高速度：[/b] 296 km/h
[b]0–100 km/h：[/b] 3.2 秒
[b]載貨容量：[/b] 2 個欄位
[b]經銷商：[/b] Manhattan Luxury Cars 和 The Hamptons Axis
[b]價格：[/b] $250,000

加速與煞車皆經過調校，以盡量貼近真實車輛。

此車可在私人司機服務中登記。
