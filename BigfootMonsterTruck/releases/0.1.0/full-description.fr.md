[h1]Bigfoot Monster Truck[/h1]
[b]Pourquoi attendre derrière les embouteillages quand on peut simplement rouler dessus ?[/b]

Le [b]Bigfoot Monster Truck[/b] apporte une façon légèrement moins civilisée de se déplacer en ville. Il est énorme, il est bruyant et oui : vous pouvez vraiment rouler sur les autres véhicules.

[h2]Fonctionnalités[/h2]
[list]
[*]Un Bigfoot Monster Truck entièrement pilotable.
[*]Des pneus gigantesques capables de grimper sur les autres véhicules et de les franchir.
[*]Bruyant. Très bruyant. C'est un monster truck, après tout.
[*]Équipé de l'inimitable [b]klaxon TOOT[/b] pour les rares occasions où rouler sur les embouteillages ne suffit pas.
[*]Disponible chez [b]General US Trucks[/b].
[*]Prix d'achat : [b]345 000 $[/b].
[/list]

[h2]Stationnement[/h2]
Le stationnement en créneau n'est pas pris en charge.
Pas à cause d'une limitation technique.
[b]Il ne rentre tout simplement pas.[/b]

Pour vous garer normalement, il vous faudra [b]deux places de stationnement[/b] – et oui, vous paierez aussi [b]deux fois les frais de stationnement[/b].
Considérez cela comme la taxe Bigfoot.
