Όταν ακόμα και ένα supercar αρχίζει να φαίνεται συνηθισμένο, υπάρχει η [b]Koenigsegg Jesko[/b] — κτηνωδώς γρήγορη, απίστευτα αποκλειστική και κατασκευασμένη πάνω απ’ όλα για ένα πράγμα: τις επιδόσεις.
